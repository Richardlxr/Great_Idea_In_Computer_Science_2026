# Advance 路线图：从一次注意力到一个会写小说的 GPT

> 主线（阶段 1–4）对应任务书 G1–G5，**不需要训练**，只要 CPU；
> 阶段 5 是 G6-A，用 4060Ti（WSL）训练一个字符级 GPT 写网络小说，从小模型跑通，逐档放大；阶段 6 是 G7 讲解。
> 每阶段一篇任务式教程，做完一篇再写下一篇。

## 一条主线：每一步都给下一步造零件

                                      │

                                      ▼

## 两台机器怎么分工

- **Mac（现在这台）**：写代码、跑阶段 1–4 的全部检查。对拍一律用 CPU + `float64`（MPS 不支持 float64）。
- **4060Ti（8 GB，Windows 的 WSL 里）**：只在阶段 5 训练时用。代码里统一用 `get_device()` 选 `cuda → mps → cpu`，同一份代码两边都能跑。

### WSL 准备（阶段 5 前做好即可）

1. **在 Windows 上**把 NVIDIA 驱动更新到最新（580 系列或更新）。`uv.lock` 在 Linux 上锁定的是 CUDA 13 版 torch，旧驱动跑不起来。
2. **WSL 里不要装** Linux 版 NVIDIA 驱动，WSL 直接用 Windows 的驱动。在 WSL 里运行 `nvidia-smi`，能看到 4060Ti 就对了。
3. 仓库 clone 到 WSL 自己的家目录（`~/...`），**不要放在 `/mnt/c/...`**：跨系统读文件慢好几倍，数据加载会拖慢训练。
4. WSL 里装 uv，在 `AI06-Transformer-Attention` 下运行 `uv sync`（会下载约几 GB 的 CUDA 库），然后验证：
   `uv run python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name())"`，应该输出 `True NVIDIA GeForce RTX 4060 Ti`。
5. 长时间训练：在 `tmux` 里跑，关掉 Windows 的自动睡眠，训练脚本定期保存 checkpoint，断了能续。

### 模型规模：数据量决定模型能做多大

模型能做多大，限制在**数据**，不在算力：数据太少时，大模型只会把小说背下来，验证损失反而变差。
粗略经验：训练用的字数至少要有参数量的十几到二十倍。下面的时间是估算值，阶段 5a 实测后再修正。

| 档位 | 结构 | 参数量 | 建议语料 | 4060Ti 估计时间 |
| --- | --- | --- | --- | --- |
| S | 6 层，d_model=384，6 头，上下文 256 | 约 1300 万 | ≥ 1000 万字（2–3 本） | 1 小时内 |
| M | 8 层，d_model=512，8 头，上下文 512 | 约 3000 万 | ≥ 3000 万字（约 10 本） | 数小时 |
| L | 12 层，d_model=768，12 头，上下文 512 | 约 9000 万 | ≥ 1 亿字（约 25–30 本） | 约 1–2 天 |

8 GB 显存跑 L 档要用 bf16 混合精度 + 小批量 + 梯度累积，阶段 5b 教程会讲。

### 语料的使用边界

- 网络小说有版权：只用你**合法获得**的文本，只在本地训练、学习用。
- 语料、checkpoint、模型权重**一律不进 git**。这个仓库在 GitHub 上，还会向课程仓库提 PR；阶段 5 开始时先把 `data/`、`checkpoints/` 加进 `.gitignore`。
- 报告和 presentation 里只放模型**生成**的短样例和损失曲线，不贴原文。
